# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта
Проект представляет собой версию сайта интернет-магазина (каталог камней), разработанную с использованием CSS-фреймворка Bootstrap. 
КР №2 является отдельной реализацией предметной области (по сравнению с КР №1) с использованием компонентного подхода.

## Используемые технологии
- HTML5
- Bootstrap 5.3.8 (подключение через CDN)
- CSS (файл `custom.css` для минимальных доработок)
- Git / GitHub

## Структура проекта
- `index.html` — главная страница (Hero-блок, популярные товары);
- `catalog.html` — каталог товаров (карточки, значки, модальное окно);
- `product.html` — страница товара (таблица характеристик, аккордеон);
- `order.html` — форма заявки (Bootstrap-формы);
- `css/custom.css` — дополнительные стили;
- `README.md` — описание проекта.

## Реализованные компоненты Bootstrap
- `navbar` — единая адаптивная навигация на всех страницах;
- `card` — карточки товаров в каталоге и на главной;
- `btn` — кнопки (основные и вторичные варианты);
- `badge` — значки статусов товаров (Новинка, Хит, Скидка);
- `alert` — информационные сообщения;
- `modal` — модальное окно быстрой заявки;
- `form-control`, `form-select`, `input-group`, `form-check` — элементы формы заявки;
- `accordion` — блок частых вопросов на странице товара;
- `breadcrumb` — хлебные крошки на странице товара;
- `table` — таблица характеристик.

## Способ подключения Bootstrap
Bootstrap подключен через CDN (jsDelivr).
CSS подключен в `<head>`, JS Bundle подключен перед закрывающим тегом `</body>`.
